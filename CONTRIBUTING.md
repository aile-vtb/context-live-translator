# Contributing

Thank you for helping improve Context Live Translator.

1. Open an issue before a large behavior or dependency change.
2. Do not commit model weights, runtimes, recordings, transcripts, credentials,
   or personal configuration.
3. Keep live transcription, initial translation, and context revision as
   independently testable stages.
4. Preserve raw ASR text and stable segment IDs in every revision path.
5. Run Ruff and pytest on Windows before opening a pull request.

Bug reports should include the `--doctor` output with personal paths redacted,
the selected audio source kind, model family, and exact error text. Do not
attach copyrighted recordings or private transcripts without permission.
